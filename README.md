# 🌻 Chalé Girassol - Site Institucional

Um site moderno, totalmente responsivo e focado em conversão, desenvolvido para o "Chalé Girassol", localizado na Praia de Redonda, Icapuí/CE. 

Este projeto foi construído para entregar uma experiência de navegação fluida, destacando as belezas do local, construindo autoridade (através de prova social) e facilitando o processo de reserva direta via WhatsApp e plataformas parceiras.

## 🚀 Funcionalidades

- **Design Responsivo (Mobile-First):** Layout adaptável para smartphones, tablets e desktops.
- **Animações e Microinterações:** Efeitos de Fade-In, transições suaves nos botões, sublinhado animado no menu e efeito Parallax na seção principal.
- **Navegação Suave (Smooth Scrolling):** Deslizamento elegante entre as seções na página principal (Single Page Application feel).
- **Múltiplas Páginas:** Páginas individuais e detalhadas para cada chalé (`tucutu.html`, `canario.html`, `turquesa.html`) com galeria de fotos e grid de comodidades.
- **Prova Social:** Seção de avaliações estilizada para gerar confiança aos futuros hóspedes.
- **Foco em Conversão (Call to Actions):** Botões com links diretos integrados ao WhatsApp (com mensagem pré-definida), Airbnb e Booking.

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as tecnologias base da web, sem dependências externas pesadas, garantindo alta performance e carregamento rápido:

- **HTML5:** Semântica e estruturação do conteúdo (múltiplas páginas).
- **CSS3:** Estilização avançada com Flexbox, CSS Grid, Variáveis Globais (`:root`), Keyframes para animações e Media Queries para responsividade.
- **JavaScript (Vanilla):** Lógica simples e eficiente para manipulação do DOM e navegação suave entre as seções.
